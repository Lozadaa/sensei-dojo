By the end you’ll find any commit and see what it changed.

HEAD and its ancestors

git log --oneline shows one commit per line. HEAD~1 is the one before yours; git show shows what changed.

Do

  1. Make two more commits to notes.txt.
  2. git log: scroll with the arrows and leave.
  3. git log --oneline.
  4. git show HEAD~1.
  5. Press «I did it».

Prove it

One question at a time. The sensei grades right here.

  1. Which option shows one commit per line?
  2. Which key closes git log?
  3. How do you name the commit before HEAD?
Wrap-up

You read your history like a book.
